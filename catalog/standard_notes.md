# 견적 표준문구 & 운영원칙 (출처: 표준견적서 v2 · 09_운영원칙)

## VR 중복과금 방지 표준문구 (견적서 자동 삽입)

> IPX-Series는 통신채널·ARS·CRS·기본녹취 수집 플랫폼으로 적용되며, IPX-VR/STT는 해당 녹취데이터를 STT 변환·검색·분석하는 확장 모듈입니다. 본 구성에서는 기본 녹취 기능을 중복 과금하지 않습니다.

## 운영원칙 v2.0

1. VR 중복방지 — IPX-Series VR=녹취 수집, VR/STT=STT·검색·분석 확장으로 설명
2. STT 가격현실화 — VR/STT 기본 패키지 4,500만~5,500만원 주력 가격대
3. 고부가화 방식 — 1억원 이상은 STT 단가가 아닌 악성민원 탐지·증거관리·연동·리포트로 구성
4. 조달표현 — 제품명=기술명, 견적서 사업명=공공가치명
5. 무상제공 금지 — 계약품목 외 기능·연동·설치·교육·리포트는 반드시 견적 항목화
6. 유통사 할인통제 — 할인율·승인권자·사유 기록, 등급별 하한 준수
7. 기존 고객 업셀링 — IPX-Series 보유 고객은 STT 분석 업그레이드로 제안
8. 신규 고객 패키징 — IPX-Series+VR/STT+분석모듈을 역할별 분리 제안
9. 식별번호 조합 — 등록품목 우선, 신규후보·커스터마이징 분리 표기
10. 성과관리 — 납품요구명·품목·식별번호·수량·할인율·지역·파트너·패키지명 월별 기록

- [ ] 등록품목·신규후보·커스터마이징 항목이 구분되었는가?
- [ ] 할인율과 승인권자가 기록되었는가?
- [ ] 유통사 공급가·최종고객 견적가가 혼재되지 않았는가?
- [ ] 무상 연동·무상 개발·무상 교육 항목이 없는가?
