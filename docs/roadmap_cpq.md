**확정일:** 2026-06-26 · **기준 전략:** 표준견적서 NewVersion v2.0(xlsx), 전략 NewVersion v3.0(pptx)

## 전략 정렬 요약 (구버전 폐기 기준)

- 110만원 **단일 IP채널 SKU** 의존 → **6계층** 구조: `Core / Channel / User / Interface / Module / Service`
- STT 고가 엔진(2,000만원대) 폐기 → **VR/STT 기본 패키지 4,500만~5,500만원** 현실화
- "제품 기능" 판매 → **공공가치 명분**(공무원 보호·민원분석·재난복지·증빙) 판매
- 신규: 식별번호 조합표, 등록상태 구분(등록/신규후보/커스터마이징), 이중가격(권장제안가/표준유통공급가), 할인승인정책, VR 중복과금 방지 문구

## 확정 결정사항 (2026-06-26 시드 검토 / 방향 수정)

1. **이원화(Dual-Track) 병행** — 신규 패키지 구조로의 전면 전환은 즉시 실행이 어려우므로, 당분간 두 방식을 **병행 지원**한다.
   - **Track A (레거시 유지):** `package_price.xlsx#base_item(A)` 기반 기존 단가합산 방식. 현장 영업이 익숙한 방식으로 즉시 견적 가능.
   - **Track B (신규 패키지):** `package_price.xlsx#base_product(B)` 기반 `Core + 채널라이선스 + 모듈라이선스 + 부가서비스` 계층 패키지 CPQ. 예산대(A~E) 프리셋·명분·이중가격·할인승인.
   - 견적 시작 시 **모드 선택**(레거시 / 패키지). 추후 운영 데이터 축적 후 통합 여부 재결정.
2. **C(악성민원) 프리셋** — 산출합계 147.15M 정가 유지, 권장가격대(100~130M)는 **패키지 할인(D/C) 전제**로 맞춤. 시드 수정 없음.
3. STT 채널 단위("CH 또는 분석라이선스") 규격 미확정 — 조달 재등록 시 단위 확정 필요(Phase 0 잔여 확인사항).

## Phase 0 — 데이터모델 재설계 (기반)

**신규 카탈로그 스키마 (`package_price.xlsx` 우선, `catalog/` 시드 CSV fallback):**

- `base_product(B)` — 상품계층·내부명·대외명·단위·대외기준가·권장제안가·표준유통공급가·전략파트너하한·공급가율·등록상태·식별번호·가격정책·비고·항목코드 (출처: 02_가격마스터_v2)
- `registered_skus.csv` — 디지털서비스몰 등록품목 + 식별번호·계약종료일·전략역할 (출처: 01_조달등록품목)
- `service_packages.csv` — 10개 공공가치 패키지: 명분·조합제품·수요처·목표가격대·납품요구명 예시 (출처: 04_서비스패키지_v2)
- `package_presets.csv` + `package_preset_items.csv` — 예산대별 A~E 프리셋 구성항목 (출처: 05_패키지산출_예시)
- `discount_policy.csv` — 파트너 등급별 할인 한도 (출처: 07_유통사운영정책)

**기존 estimates DB 확장:** `estimate_items`에 `tier`(계층)·`identifier_no`(식별번호)·`reg_status`(등록상태)·`proposed_price`·`supply_price`·`discount_rate` 컬럼 추가 (마이그레이션).

## Phase 1 — 패키지·CPQ 견적엔진

- A~E 예산 프리셋 선택 → 자동 구성 → 수량·할인 조정
- 할인율 입력 시 파트너 등급별 하한 검증(경고)
- 권장제안가 / 표준유통공급가 **이중 계산** (대외용 vs 파트너용)
- VR 중복과금 방지 표준문구 자동 삽입

## Phase 2 — 명분 기반 제안 보조

- 사업명/공공명분 선택 → 적합 패키지 추천 + 납품요구명 예시 자동 채움
- 식별번호 조합표 자동 생성 (등록/신규후보/커스터마이징 구분)

## Phase 3 — 출력 2종 + 검증

- 실제 양식 기반 **업체용/소비자용 2시트** 견적서 (Excel + PDF)
- 제출 전 체크리스트(09_운영원칙) 자동 검증
